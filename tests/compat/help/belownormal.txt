belownormal - run a command at BELOW_NORMAL priority

usage: belownormal <command> [args...]

The priority is a Job Object limit, so it applies to the whole process tree,
including children that ask for another priority. Waits for the command and
exits with its exit code (127 if it is not found). Everything after the tool
name is the command, exactly as given.

Use it to keep long builds/tests from making the desktop sluggish.

Same as: wnice -p belownormal -- <command> [args...]

examples:
  belownormal npm run build
  belownormal cmd /c "build.bat && test.bat"
  belownormal capc 50 cargo test        (chained: belownormal priority plus a 50% CPU cap)
