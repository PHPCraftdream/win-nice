## Decisions
- Single Rust multicall exe over separate exes or PowerShell wrappers; exe built in CI, shipped in npm, never compiled on user machines.
- Tool .exe files are hardlinks of the INSTALLED wnice.exe copy, never of the npm package file (EBUSY on upgrade otherwise).
- Bare command names resolve from absolute PATH entries only (never cwd); not found → 127; cmd builtins must be wrapped in `cmd /c`.
- Priority is a job-wide limit; high/realtime without SeIncreaseBasePriorityPrivilege fall back to root-only HIGH with a stderr note.
- CI and engines: Node 24 only (`engines.node >=24`), owner decision.
