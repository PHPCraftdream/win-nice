## Decisions
- Single multicall Rust exe `wnice.exe` over 14 separate exes or a PowerShell/.ps1+DLL wrapper; legacy names keep positional syntax.
- Exe built in CI and shipped in the npm tarball, not committed to git; users never compile.
- Tree-wide priority via JOB_OBJECT_LIMIT_PRIORITY_CLASS (verified for AboveNormal; High refused with 1314 without elevation -> root-only fallback with a stderr note).
- Visible windows prevented structurally (hidden desktop + Job cap via guarded.ps1) rather than by per-call flags alone.
- Upgrades must rename running .exe aside (.old-N) because Windows locks running executables.
